# CareerPilot AI 🚀

An AI-powered career guidance platform that helps students and job seekers analyze their resumes, improve ATS scores, get personalized career advice, practice interviews, and create learning roadmaps.

## ✨ Features

* 📄 Resume Upload & Analysis
* 📊 ATS Score Analysis
* 🤖 AI Career Advice
* 🎤 AI Interview Preparation
* 🗺️ Personalized Learning Roadmap
* 🔐 User Registration & Login
* 💾 SQLite Database
* 📑 PDF Resume Text Extraction

## 🛠️ Technologies Used

* Python
* Flask
* SQLite
* Google Gemini AI
* HTML
* CSS
* JavaScript
* PyPDF2

## 🤖 AI Features

CareerPilot AI uses Google Gemini to provide personalized:

* Resume analysis
* Career guidance
* Interview questions and preparation
* Learning roadmaps

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Banti9569/CareerPilot-AI.git
cd CareerPilot-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```text
GEMINI_API_KEY=your_api_key_here
```

Run the application:

```bash
python app.py
```

Then open:

```text
http://127.0.0.1:5000
```

## 🔒 Security

API keys and user-uploaded files are excluded from GitHub using `.gitignore`.
